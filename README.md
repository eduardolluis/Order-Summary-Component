# Order Summary Component

A responsive order-summary UI component built as a frontend layout exercise.

## Highlights

- Order summary card
- Pricing and plan presentation
- Responsive styling
- Reusable visual component structure

## Tech Stack

- HTML5
- CSS3

## Run Locally

```bash
git clone https://github.com/eduardolluis/Order-Summary-Component.git
cd Order-Summary-Component
```

Open `index.html` in your browser.
